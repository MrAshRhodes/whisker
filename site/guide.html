User guide

Permissions

Whisker uses the Accessibility permission to observe and remap mouse buttons and scrolling. On first launch, open System Settings > Privacy & Security > Accessibility, allow Whisker, then relaunch it. Signed releases keep this permission across updates.

Updates

Copies downloaded from GitHub Releases can check for updates from the Whisker menu with Check for Updates…, or automatically when enabled in Settings. Whisker always asks before downloading and again before installing and relaunching. Every update is verified against Whisker's update signing key and Apple's Developer ID signature before it is installed.

Copies installed with Homebrew are updated by Homebrew:

brew update && brew upgrade --cask whisker

Switching between Homebrew and direct downloads

Use one installation method at a time. To move a direct download to Homebrew, quit Whisker, delete it from Applications, then run brew install --cask mrashrhodes/tap/whisker. To move from Homebrew to a direct download, run brew uninstall --cask whisker first, then install the downloaded app. Your settings are kept either way.
