Getting started

Whisker runs on macOS 14 Sonoma or later. Install it with Homebrew:

brew install --cask mrashrhodes/tap/whisker

or download the DMG or ZIP from the latest release. Before opening a download, check it in Terminal with the matching checksum file from the same release, for example shasum -a 256 -c Whisker-0.1.0.dmg.sha256, and continue only if it reports OK. Then move Whisker.app to your Applications folder and open it.

On first launch Whisker opens its settings window and asks for the Accessibility permission. Once that is granted, choose a device and start assigning buttons. Whisker keeps running in the menu bar when you close the window.

Permissions

macOS only lets an app see and change mouse input if you have allowed it under Accessibility. Whisker uses this to notice when you press a button or turn the wheel, and to replace that event with the action you chose. It also reads which app is in front so it can pick the right profile. It does not record what you type or send anything off your Mac.

  1. In Whisker's welcome screen, click Open Accessibility Settings.
  2. In System Settings › Privacy & Security › Accessibility, turn on Whisker. You may need to enter your password.
  3. Return to Whisker. It notices the change within about a second and starts working; you do not need to relaunch it.

If you later turn the permission off, Whisker stops changing input straight away, its menu bar icon is shown crossed through, and its menu offers Grant Accessibility Access….

Releases are signed with the same Apple Developer ID each time, so the permission carries over when you update. A copy you built yourself, or one signed differently, counts as a new app and has to be allowed again. See Troubleshooting.

Menu bar and login item

Whisker's menu bar item lets you switch Whisker on or off, open its settings, check for updates and quit. Switching it off passes every mouse event through unchanged and restores the original pointer settings, without quitting.

Whisker can open automatically when you log in. Turn this on or off in its settings. If macOS needs your approval for the login item, Whisker says so and offers a button that opens System Settings › General › Login Items.

Devices

The devices list shows the mice and trackballs that are connected now, by USB, a wireless receiver or Bluetooth. Devices appear and disappear as you connect them, and Whisker remembers settings for each one, so they come back when the device reconnects. Wheel and pointer settings are stored per device; button mappings belong to profiles.

Trackpads and Magic Mouse rely on gestures, so Whisker does not remap their buttons. Scroll reversal can still be turned on for a Magic Mouse.

Buttons

To change a button, add a mapping, press the button you want to change (or pick it from the list), then choose an action. Add modifier keys (⌘ ⌥ ⌃ ⇧ fn) to a mapping to make it apply only while those keys are held. A mapping with the exact modifiers you are holding is used first, then one with no modifiers; otherwise the button works as normal.

The primary (left) button cannot be remapped on its own, so you can always click. It can be remapped in combination with a modifier key.

Actions

ActionWhat it does
ClickActs as another mouse button, optionally with modifier keys. Holding the button holds the click, so dragging works.
Keyboard shortcutPresses a key combination. It can repeat while the button is held, at your keyboard's repeat rate.
Back / ForwardSends ⌘[ or ⌘], which most browsers and Finder understand.
MediaPlay or pause, next or previous track, volume up or down, mute, and display brightness. Volume can move in finer steps.
Mission ControlMission Control, application windows, show desktop, Launchpad or Notification Centre.
SpacesMove one Space left or right, or go to Desktop 1 to 9.
Switch appGo to the next or previous app, in order of recent use.
OpenOpen a file, folder, app or web address.
Do nothingIgnore the button completely.

Mission Control, Spaces and some other system actions use your own keyboard shortcuts from System Settings › Keyboard › Keyboard Shortcuts. If the matching shortcut is turned off, Whisker shows a warning next to the action with a button to open that pane. Whisker never changes those shortcuts itself.

Scrolling

Direction

Reverse the vertical or horizontal wheel for each device. This is separate from the system's natural scrolling setting and affects only that device, so a trackpad keeps scrolling the way it did.

Lines per notch

Choose how many lines each click of the wheel scrolls, from 1 to 20. This is set per profile, so one app can scroll further than another. It applies to wheels that click in steps; smooth-scrolling devices such as trackpads and free-spinning wheels are left as they are.

Wheel with modifier keys

Turning the wheel while holding a modifier can run an action instead of scrolling, for example ⌥ and the wheel to change the volume. A quick turn of several notches counts as one action, so a shortcut is not triggered many times; actions such as volume can be set to repeat for each notch instead.

Pointer speed

Where the device and macOS allow it, Whisker can set pointer speed and acceleration for each device, or turn acceleration off for a linear response.

If a change more than doubles the speed, Whisker asks you to confirm it. If you do not confirm within five seconds, it goes back to the previous setting, so you are never stuck with a pointer too fast to use.

Whisker records each device's original values before changing them and restores them when you turn the device's settings off, switch Whisker off or quit. If Whisker did not quit cleanly, it restores them the next time it opens.

Per-app profiles

The Default profile applies everywhere and cannot be deleted. Add a profile for an app, and optionally a particular device, to change buttons or scrolling only there. Whisker switches profiles automatically when you change apps.

A profile only needs the mappings that differ. Anything it does not set comes from the Default profile. When more than one profile could apply, the most specific wins: one for this app and this device, then this app on any device, then this device in any app, then Default.

Settings file

Whisker saves everything to one JSON file:

~/Library/Application Support/Whisker/settings.json

Use Export Settings… to save a copy, for example to move your setup to another Mac, and Import Settings… to load one. Whisker checks an imported file before using it and leaves your current settings unchanged if the file is not valid.

You can edit the file by hand while Whisker is not running. Settings that a newer version of Whisker added are kept even if your version does not use them. Whisker also keeps a small state.json beside it with the original device values it needs to restore; do not edit that file.

Updates

Copies downloaded from GitHub Releases can update themselves. Choose Check for Updates… from Whisker's menu bar menu, or Check Now under Updates in the settings window. Automatic checks are off until you choose Daily, Weekly or Monthly there; choose Never to turn them off again.

Whisker always asks before downloading an update, and again before installing it and relaunching. Every update must have a valid Whisker update signature and Apple Developer ID signature before it is installed. Only stable releases are offered. Update checks are the only network requests Whisker makes.

Copies installed with Homebrew are updated by Homebrew, and Whisker shows the command with a Copy Command button. Quit Whisker, then run:

brew update && brew upgrade --cask whisker

Copies you build from source cannot update themselves.

Switching between Homebrew and direct downloads

Use one installation method at a time. To move a direct download to Homebrew, quit Whisker, delete it from Applications, then run brew install --cask mrashrhodes/tap/whisker. To move from Homebrew to a direct download, run brew uninstall --cask whisker first, then install the downloaded app. Your settings are kept either way.

Uninstalling

  1. In Whisker's settings, turn off opening at login. Then quit Whisker from its menu bar menu; this restores your original pointer and scroll settings.
  2. Delete Whisker from Applications, or run brew uninstall --cask whisker if you installed it with Homebrew.
  3. In System Settings › Privacy & Security › Accessibility, select Whisker and click the remove (−) button. Or run tccutil reset Accessibility io.github.mrashrhodes.whisker in Terminal.
  4. If Whisker is still listed in System Settings › General › Login Items, remove it there.
  5. To remove your settings too, delete ~/Library/Application Support/Whisker. With Homebrew, brew uninstall --cask --zap whisker does this for you.

Troubleshooting

Buttons or scrolling do nothing

Check that Whisker is switched on in its menu and allowed under Accessibility. If the menu bar icon is crossed through, choose Grant Accessibility Access….

Whisker is allowed but still does not work

This usually happens after installing a copy signed differently, such as one you built yourself. Remove Whisker from the Accessibility list, or run tccutil reset Accessibility io.github.mrashrhodes.whisker, then open Whisker and allow it again.

A system action does nothing

Turn on the matching shortcut in System Settings › Keyboard › Keyboard Shortcuts. Keyboard shortcuts may also be ignored while a password field is active; this is a macOS protection.

Back and forward do nothing in one app

That app does not use ⌘[ and ⌘]. Add a profile for it and map the buttons to the shortcuts it does use.

Something else

Search the issues or open a new one with your Whisker and macOS versions and the mouse you use.
