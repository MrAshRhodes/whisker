General arrangement

Every control, annotated.

Pick a part and a profile. Whisker looks at the app in front and the mouse you're using, picks the closest profile and lays it over Default, so an app profile only holds what it changes.

Wheel and pointer

Measured by the notch.

Whisker counts wheel notches rather than pixels, and lets each mouse keep its own pointer feel. Both instruments below are live.

Notes

Private by design.

  1. No telemetry, analytics or accounts.

  2. The only thing Whisker asks the network for is an update check, and that's off until you pick a schedule or press Check Now.

  3. Accessibility access lets Whisker see and change mouse input. It doesn't read what you type.

  4. Your settings stay on your Mac, in ~/Library/Application Support/Whisker/settings.json.

  5. Every line is open source under the MIT licence, on GitHub.

Build

Build it today.

Until the first signed release, you build Whisker yourself. It takes a couple of minutes with Apple's free developer tools.

  1. Install Xcode, or just the Command Line Tools with xcode-select --install. Whisker needs Swift 5.9 or later.

  2. Clone the repository and build the app:

git clone https://github.com/MrAshRhodes/whisker.git
cd whisker
make app

The app lands in dist/Whisker.app. Move it to Applications and open it, or use make run to build and open in one go.

Good to know

  1. Your build is signed just for your Mac, so macOS asks for Accessibility access again after each rebuild.

  2. A copy you built can't update itself. Pull the latest source and build again.

  3. After the first release, download signed builds from Releases or install with Homebrew.

  4. New to Whisker? The guide walks through the first run.
