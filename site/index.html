Whisker

Make every button on your mouse or trackball useful, and scrolling feel right, on macOS.

Download Read the guide

Free and open source · macOS 14 or later · Apple silicon and Intel

What it does

Whisker lives in the menu bar. Set it up once and it works in the background, switching settings as you move between apps.

  • Button remapping

    Give the middle and side buttons a new job. Hold ⌘, ⌥, ⌃, ⇧ or fn to give the same button more than one.

  • Useful actions

    Keyboard shortcuts, back and forward, media keys, Mission Control, Spaces, app switching, or opening a file or web address.

  • Scrolling your way

    Reverse the wheel for a mouse without touching the trackpad, set the lines per notch, and use the wheel with a modifier key for actions such as volume.

  • Per-app profiles

    Different buttons and scrolling for each app. Anything a profile leaves alone comes from your default settings.

  • Pointer speed

    Set speed and acceleration for each device, where supported. Large increases must be confirmed, or they revert by themselves.

  • Private by design

    No accounts, analytics or telemetry. Nothing leaves your Mac except update checks you turn on yourself.

Made for the Mac

Whisker follows the conventions of macOS rather than replacing them.

Fits in

A native settings window, a menu bar item you can switch on and off, an optional login item, and light and dark appearance.

Plays safe

The primary button always clicks. Pointer and scroll settings return to their original values when Whisker quits. Trackpads keep their gestures.

Keeps up

Mice and trackballs appear as soon as you connect them. Settings live in one JSON file you can export, back up and import.

Install

Whisker needs macOS 14 Sonoma or later.

Homebrew

brew install --cask mrashrhodes/tap/whisker

Homebrew keeps this copy up to date.

Direct download

Download the DMG or ZIP from the latest release, check it against its .sha256 file, and move Whisker to Applications. This copy updates itself when you ask it to.

Releases are signed with Apple Developer ID and notarized by Apple. On first launch Whisker asks for the Accessibility permission, which macOS requires before an app can change mouse input. The guide explains why and how.
