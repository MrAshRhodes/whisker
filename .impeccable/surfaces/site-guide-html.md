# Whisker user guide

Mode: Read.

Help a Mac user install Whisker, grant permissions and understand every setting.
The website identity remains in the green header, compact mark and Anybody
headings, while the body uses quiet adaptive reading surfaces and Atkinson
text. No marketing installations interrupt instructions.

Keep every existing section anchor, usable tables, wrapping inline paths,
scrollable commands, skip navigation and a desktop sticky contents list.
Mobile moves contents above the article. All instructions work without
JavaScript; the optional TOC observer only adds current-section indication.

Download and Homebrew are the main installation paths, with build from source
documented as an alternative. The 404
shares the identity, offers real home/guide links and uses root-relative
/whisker/ URLs so it also works at unknown nested paths.
