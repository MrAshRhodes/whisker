# Pointer playground

Mode: Persuade.

Whisker introduces free, open-source macOS mouse and trackball controls to
people deciding whether to build it. The primary action is Build from source;
no signed download exists yet.

The first viewport is a working, diagonal-stage installation: compact wordmark,
short true purpose, wide headline, oversized original lilac mouse, native
profile/part choices and a readable mapping result on a spring-green field.
The result is an example, not a change to the visitor's system.

The visitor then tries line distance/reversal and pointer response. The latter
is expressly illustrative and retains its five-second confirmation safety.
Feature links, privacy, unshipped plans and source instructions complete the
decision. Each scene changes colour, scale or density rather than repeating
cards. Mobile stacks naturally; no interaction depends on hovering.

Authority: DESIGN.md for the website identity; PRODUCT.md and guide.html for
product truth. Preserve strict CSP, local assets, native keyboard controls,
all existing guide deep links, both colour schemes and reduced motion.
