# Whisker website

<!-- impeccable:product-schema 1 -->

## Platform

web

This record describes the public website. Whisker itself is a native macOS
application, not a web application.

## Users and purpose

The website introduces Whisker to Mac users who want more control over their
mouse or trackball. It explains the available controls, demonstrates their
effects, and leads readers to the setup guide and source repository.

## Capabilities and constraints

- Whisker requires macOS 14 or later.
- The current installation path is building from source. A signed binary
  download must not be advertised until a release actually exists.
- Demonstrations explain behavior; they are not screenshots of the native app
  or measurements of its performance.
- Planned features must remain distinguishable from implemented features.
- The website is static and published through GitHub Pages.
- Whisker is MIT-licensed and does not include telemetry.

## Brand commitments

Keep the Whisker name. Use direct, understandable language and original visual
work. The website must not name the reference applications used during product
development or imply an affiliation with other products.

## Evidence on hand

The repository contains the application source, setup guide, site interaction
demonstrations, and automated checks. There are no customer testimonials,
adoption figures, or benchmark results to use as marketing claims.

## Product principles

- Show what a setting changes instead of merely naming it.
- Keep installation and release status honest.
- Make useful documentation accessible without JavaScript.
- Preserve keyboard access, legible text, and reduced-motion preferences.
